# Farm Icon Color – Logo converter / Convertisseur de logos / Logo-Konverter

**[FarmIconColor-LogoConverter.html](FarmIconColor-LogoConverter.html)**

## English
1. Open `FarmIconColor-LogoConverter.html`, then click **Download raw file** (download icon, top right of the file view).
2. Open the downloaded file in your web browser (double-click). It works offline: no image is sent over the Internet.
3. Drop your image (PNG, JPG, WEBP, SVG or DDS), give the logo a name and download the `.xml` file.
4. Put the `.xml` in `Documents/My Games/FarmingSimulator2025/modSettings/FS25_farmIconColor/customLogos/`.
5. In game (admin): farm edit window → **Logos** → **Import** (INSERT).

## Français
1. Ouvrez `FarmIconColor-LogoConverter.html`, puis cliquez sur **Download raw file** (icône de téléchargement, en haut à droite du fichier).
2. Ouvrez le fichier téléchargé dans votre navigateur (double-clic). Il fonctionne hors ligne : aucune image n'est envoyée sur Internet.
3. Déposez votre image (PNG, JPG, WEBP, SVG ou DDS), donnez un nom au logo et téléchargez le fichier `.xml`.
4. Placez le `.xml` dans `Documents/My Games/FarmingSimulator2025/modSettings/FS25_farmIconColor/customLogos/`.
5. En jeu (admin) : fenêtre de modification de ferme → **Logos** → **Importer** (INSER).

## Deutsch
1. Öffne `FarmIconColor-LogoConverter.html` und klicke auf **Download raw file** (Download-Symbol oben rechts in der Dateiansicht).
2. Öffne die heruntergeladene Datei in deinem Browser (Doppelklick). Sie funktioniert offline: kein Bild wird ins Internet gesendet.
3. Lege dein Bild ab (PNG, JPG, WEBP, SVG oder DDS), gib dem Logo einen Namen und lade die `.xml`-Datei herunter.
4. Lege die `.xml` in `Documents/My Games/FarmingSimulator2025/modSettings/FS25_farmIconColor/customLogos/`.
5. Im Spiel (Admin): Hof-Bearbeitungsfenster → **Logos** → **Import** (EINFG).
